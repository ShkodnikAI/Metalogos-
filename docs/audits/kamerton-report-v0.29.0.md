## 5. Честные поправки протокола Камертона (дословно из t92, без переформулировок)

1. «R2 в их формулировке (пробелы внутри скобок) даёт тихую потерю,
   дословный SQL_ERROR — форма с пробелами вокруг точки».
2. «хвост pattern-тела при D2 НЕ исполняется (их матрица: „выполняется"
   — неточна)».

Обе поправки — к матрице Камертона на их сборке: они уточняют, какая
именно форма давала какой симптом; на вердикты «исправлено в v0.29.0»
не влияют (все формы behave идентично после №611/№612 — таблица §2).

Why Metalogos

Most languages give you functions and classes. Metalogos gives you seven semantic primitives that map to how AI systems actually reason.

Security by Design

XSS, SQL injection, and plaintext secret leakage are rejected by static checks on the listed data-flow shapes. Opaque types (Html, Query, Secret) enforce safety at the language level. Like Rust's ownership model applied to web security.

AI-Native

Learnable patterns are a language construct, not a library call. LLM invocation is as natural as calling a function — with automatic prompt engineering, few-shot caching, sandboxed execution, and runtime adaptation.

Full-Stack in One File

A single .mlog file defines data models, AI logic, HTTP routes, templates, database queries, authentication, and bot webhooks. From prototype to production without leaving the language.

7 pillars: Entity, Pattern, Flow, Memory, Rule, Learn, Adapt
40+ built-in functions (string, math, web, crypto, auth)
Fluid types: probabilistic superposition
Confidence propagation through pipelines

OWASP Top 10

Each threat addressed at the language level, with documented boundaries.

A02Cryptographic FailuresSecret opaque type — no print, no to_string; AES-256-GCM encryption
A03InjectionQuery opaque type — parameterized only, SQL is a literal not a variable
A04Insecure DesignOpaque types, static audit, compiler-enforced checks — see Known boundaries

A06Vulnerable ComponentsMinimal dependency tree; lockfile enforcement
A07Auth Failureshash_password / verify_password; HMAC-SHA256 signed sessions
A08Data Integrity FailuresCSRF double-submit on all mutating routes; signed cookies
A09Logging FailuresAudit log for require failures, adapt mutations, unsafe_html
A10SSRFLLM calls in sandbox with forbidden: [network]; outbound HTTP restricted

Architecture

From source to effects in five stages. Pest PEG grammar, hand-written AST, semantic analysis, and a tree-walking interpreter — all in Rust.

Get Started

Build from source. Run your first program in under a minute.

# Clone the repository
git clone https://github.com/ShkodnikAI/Metalogos-.git
cd Metalogos-

# Build and install the CLI
cargo install --path .

# Run a program
mlog run examples/m1_hello.mlog
HELLO, METALOGOS!!

# Interactive REPL
mlog repl

# Semantic check (no execution)
mlog check examples/p6_full_app.mlog

# Serve a web application
mlog serve examples/p6_full_app.mlog
Listening on 0.0.0.0:8080

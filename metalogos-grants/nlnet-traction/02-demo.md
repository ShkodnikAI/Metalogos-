# The demo arc: language → serve → taint labels → action-ledger

Draft for the NLnet/Restack traction package (№549). The arc shows the
project's central claim in one command — information-flow labels and
the capability/ledger machinery are the LANGUAGE's own semantics, not
a bolted-on library.

## One command

```bash
cargo build --bin mlog
bash scripts/demo_traction.sh
```

Exit code 0 = every leg reproduced. The script composes the public
examples of this repository VERBATIM — the demo shows the shipped
behavior, not a staged script.

## The legs

### Leg 1 — static taint labels (the refusal precedes runtime)

`mlog check examples/w1_kitchen_camera.mlog`

A camera in a private room declares its stream `label: private`; the
pattern tries to write a frame to a file. The compilation is DENIED
with the explainable reason — the class (`SECRET_LEAK`), the rule
(`SINK_CLEARANCE`, private egress), the exact node and the failed
threshold. Not a runtime crash, not a silent pass: the dataflow
violation is refused before the program exists.

### Leg 2 — serve (the same runtime as a live HTTP server)

`mlog serve` (a hello route) + `curl /hello`.

The language that just refused the leak runs as a plain HTTP server —
the gate stack (env, exec, egress, consent) is active in the serving
context, per-request, by default.

### Leg 3 — the action-ledger (the signed, externally verifiable trail)

`mlog run examples/w2_ledger.mlog`

An N(1) quota grant meters ONE destructive DELETE: the granted call
runs and journals itself (the ledger entry is a side effect of the
action path — there is no "also log it" call), the second call
exhausts the quota and refuses (`GRANT_EXHAUSTED` → the typed deny
event, handled by the exhaustive `on_deny` handler), the signing key
rotates, the chain is exported — and `mlog ledger verify` validates
the exported file with pure hash + Ed25519, WITHOUT the Metalogos
runtime present.

## Why this arc (the honest framing)

The three legs are the project's design center: authorization as
dataflow (the labels), refusals that explain themselves (the typed
deny reasons), and irreversible actions that leave evidence (the
signed ledger). The metrics one-pager (`01-metrics-one-pager.md`)
carries the repository facts with dates; the numbers are generated by
checked-in scripts, the floors move only one direction, and the gate
record is machine-verified in CI.
